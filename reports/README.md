# Reports

This folder contains selected text reports copied from the current working
project. It intentionally excludes raw logs, figures, and large result folders.

Key files:

- `study_a_bc_findings.md`: parameter-space SGLD diagnostic and UQ comparator
  findings.
- `sandwich_correction_findings.md`: last-layer Godambe/sandwich correction
  findings.
- `omega_vs_sandwich_explanation.txt`: why omega calibration and sandwich
  correction are related but not automatically equivalent.
- `sgld_literature_and_extension_plan.md`: literature-guided plan for SGLD,
  generalized Bayes, and non-conjugate loss extensions.
- `variance_correction_plan.md`: variance correction study plan.
- `horizon_diagnostic_findings.md`: horizon-specific diagnostic notes.
